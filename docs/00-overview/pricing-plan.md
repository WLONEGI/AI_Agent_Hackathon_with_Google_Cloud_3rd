# 料金プラン

> **TL;DR**: 2プラン構成。Free Tier（無料・3回/月・4ページ）、Premium Tier（$9.99/月・10回/月・8ページ・優先処理）。Premium転換率20%で黒字化、利益率66%。

## 料金体系

### プラン比較表

| 項目 | Free Tier | Premium Tier |
|------|-----------|--------------|
| **月額料金** | **$0** | **$9.99** |
| **月間生成回数** | 3回 | 10回 |
| **1回あたりページ数** | 最大4ページ | 最大8ページ |
| **画像品質** | 標準 | 高品質 |
| **処理優先度** | 通常 | 優先処理 |
| **データ保存期間** | 30日間 | 1年間 |
| **広告表示** | なし | なし |
| **カスタマーサポート** | コミュニティ | メールサポート |
| **商用利用** | 不可 | 可能 |
| **透かし** | あり | なし |

---

## プラン詳細

### 📱 Free Tier（無料プラン）

#### 対象ユーザー
- 初めて漫画生成を試したい方
- 月に数回程度の利用を想定
- 個人の趣味・学習目的

#### 提供内容
```yaml
基本機能:
  月間生成回数: 3回
  ページ数制限: 4ページ/回
  合計ページ数: 最大12ページ/月

画像品質:
  解像度: 1024×1024
  品質レベル: 標準
  スタイル: 全7種類対応

処理:
  優先度: 通常キュー
  平均待ち時間: 2-5分
  同時処理: 待機列あり

データ管理:
  保存期間: 30日間
  ダウンロード: PDF形式
  再生成: 期間内無制限

制限事項:
  商用利用: 不可
  透かし: "AI Generated - Free Tier"
  API利用: 不可
```

#### ユースケース
- **学習**: AI漫画生成の仕組みを理解したい
- **テスト**: 自分のアイデアが漫画になるか試したい
- **趣味**: 友人とシェアする簡単な漫画を作りたい

---

### 💎 Premium Tier（プレミアムプラン）

#### 対象ユーザー
- 本格的に漫画制作を行いたいクリエイター
- 商用利用を検討している方
- 高品質な作品を継続的に制作したい方

#### 提供内容
```yaml
基本機能:
  月額料金: $9.99/月
  月間生成回数: 10回
  ページ数制限: 8ページ/回
  合計ページ数: 最大80ページ/月

画像品質:
  解像度: 1024×1024
  品質レベル: 高品質
  スタイル: 全7種類対応
  細部表現: 向上

処理:
  優先度: 優先キュー
  平均待ち時間: 1-3分
  同時処理: 2並列まで
  処理速度: Free比1.5倍

データ管理:
  保存期間: 1年間
  ダウンロード: PDF/PNG/高解像度JPEG
  再生成: 無制限
  バージョン管理: 最大5バージョン保存

追加機能:
  商用利用: 可能
  透かし: なし
  優先サポート: メール対応（24時間以内）
  新機能早期アクセス: あり
  フィードバック優先反映: あり
```

#### ユースケース
- **クリエイター**: Webで公開する漫画シリーズを制作
- **ビジネス**: 商品紹介・サービス説明用の漫画作成
- **教育**: 教材・プレゼンテーション用コンテンツ制作
- **出版**: 同人誌・電子書籍の下書き作成

```yaml
  インフラ:
    Cloud Run処理: $0.01
    Cloud SQL: $0.003
    Cloud Storage: $0.001
    小計: $0.014

  合計原価: $0.37/回
  月間コスト (3回): $1.11/user

Premium Tier (8ページ/回):
  AI処理:
    Gemini Pro (7フェーズ): $0.20
    Imagen 4 (8画像): $0.32
    小計: $0.52

  インフラ:
    Cloud Run処理: $0.02
    Cloud SQL: $0.006
    Cloud Storage: $0.002
    小計: $0.028

  合計原価: $0.55/回
  月間コスト (10回): $5.50/user
```

### ユーザーミックス別損益

## プラン選択ガイド

### Free Tierを選ぶべき人

```yaml
推奨条件:
  ✓ 初めて漫画生成AIを使う
  ✓ 月に2-3回程度の利用
  ✓ 個人的な趣味・学習目的
  ✓ 短編漫画（4ページ程度）で十分
  ✓ 商用利用の予定なし
  ✓ データの長期保存不要

こんな場面で:
  - 友人とシェアする短編漫画
  - SNS投稿用のコンテンツ
  - アイデアの可視化・プロトタイピング
  - 学習・研究目的
```

### Premium Tierを選ぶべき人

```yaml
推奨条件:
  ✓ 週1回以上の利用予定
  ✓ 中長編漫画（8ページ）を制作したい
  ✓ 商用利用を検討している
  ✓ 高品質な作品を求める
  ✓ データを長期保存したい
  ✓ 透かしなしの作品が必要

こんな場面で:
  - Webで連載漫画を公開
  - 商品・サービスのPR漫画
  - 同人誌・電子書籍の制作
  - 教育・研修用教材作成
```

## アップグレード戦略

### Free → Premium 転換施策

#### 1. 使用量ベーストリガー
```yaml
条件: Free枠を使い切った時
施策:
  - "今月の残り回数: 0回"
  - "Premiumなら月10回まで生成可能"
  - "初月20%オフ: $7.99"

期待効果: 転換率 +5%
```

#### 2. 品質比較トリガー
```yaml
条件: 生成完了時
施策:
  - Free版とPremium版のサンプル比較表示
  - "Premium品質で再生成しますか？"
  - "30日間返金保証"

期待効果: 転換率 +3%
```

#### 3. 商用利用トリガー
```yaml
条件: ダウンロード時
施策:
  - "商用利用にはPremiumが必要です"
  - "Premiumなら透かしなし＋商用OK"
  - "ビジネス活用事例を見る"

期待効果: 転換率 +4%
```

#### 4. 保存期限トリガー
```yaml
条件: 生成から25日経過時
施策:
  - "あと5日で削除されます"
  - "Premiumなら1年間保存"
  - "今すぐアップグレード"

期待効果: 転換率 +2%
```

### 目標転換率達成パス

```
スタート: 10%
├─ 使用量トリガー実装 → 15%
├─ 品質比較トリガー追加 → 18% ← 損益分岐点突破
├─ 商用利用トリガー追加 → 22%
└─ 保存期限トリガー追加 → 24% ← 健全な利益率
```

## 価格戦略

### フェーズ別価格設定

#### Phase 1: ローンチ期（0-3ヶ月）
```yaml
戦略: 早期採用者獲得
Free Tier: 5回/月 (通常3回)
Premium Tier: $7.99/月 (20%オフ)
キャンペーン: "先着1,000名限定価格"
目標: 500ユーザー獲得
```

#### Phase 2: 成長期（3-12ヶ月）
```yaml
戦略: ユーザー基盤確立
Free Tier: 3回/月 (標準)
Premium Tier: $9.99/月 (通常価格)
キャンペーン: "年間プラン10%オフ ($107.88/年)"
目標: Premium転換率18%達成
```

#### Phase 3: 成熟期（12ヶ月+）
```yaml
戦略: 収益最適化
Free Tier: 3回/月
Premium Tier: $9.99/月
追加: 年間プラン $99.00/年 (17%オフ)
目標: Premium転換率25%維持
```

### 年間プラン

```yaml
Premium Monthly: $9.99/月 × 12 = $119.88/年

Premium Annual: $99.00/年
  割引額: $20.88 (17%オフ)
  月額換算: $8.25/月

メリット:
  - 前払いで安定収益
  - チャーン率低下
  - LTV向上
```
